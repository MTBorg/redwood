# Redwood

** Integrate your git repositories/worktrees with tmux sessions. **

Redwood is an integrator between git and tmux, meant for streamlining and
simplifying working on multiple git repositories at the same time. It allows
you to quickly open any git repository in a new tmux session, as well as
managing worktree and branches.

## Usage

### Open git repository in a new tmux session

```sh
redwood open path/to/some/repo
```

### List all git repositories in your home directory

```sh
redwood list
```
